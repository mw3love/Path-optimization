제목 :  전파조사 경로 최적화 웹앱 개발 완료 보고


1. 사업 사유

   가. KBS 전주방송총국 전파측정팀은 전북 지역 내 75개 전파 측정 지점을 2인 1조로 차량 순회하며 측정 업무를 수행 중임

   나. 기존에는 담당자가 수작업으로 방문 순서를 결정하여 이동 경로 선정에 불필요한 시간이 소요되고 최적화된 동선 확보가 어려운 상황임

   다. 이에 측정 업무의 효율화를 위해 지도 기반 지점 선택 및 최적 방문 경로를 자동 계산하는 웹앱을 개발·완료하였기에 보고함


2. 사업 개요


구분 내용 비고
사업명 전파조사 경로 최적화 웹앱 개발


개발기간 2026.04.15. ~ 2026.04.17. (3일)


대상 지점 전북 지역 75개 전파 측정 지점 타 지역 확대 가능
운영 환경 운영자 PC에서 서버 실행 후 동일 Wi-Fi 스마트폰에서 접속


주요 기술 Python Flask, OR-Tools(최적화), Leaflet(지도), OSRM(경로 계산) 무료 오픈소스
소요예산 자체 개발 (외부 용역 없음, 소요예산 없음)



3. 주요 기능

   가. 지도 기반 방문 지점 선택

      (1) 75개 전체 측정 지점을 지도 위에 시군구별 색상으로 표시

      (2) 지도 마커 클릭 또는 사이드바 체크박스로 당일 방문 지점 선택

      (3) 시군구 필터·텍스트 검색, PC 및 스마트폰 반응형 화면 지원

   나. 최적 방문 순서 자동 계산

      (1) 출발지(GPS 또는 지도 지정)와 방문 지점을 입력하면 최적 순서 자동 계산 (1초 이내)

      (2) 실제 도로 거리·소요시간 기반 계산, 네트워크 이상 시 직선거리 추정으로 자동 대체

      (3) N일 계획 기능 : 미방문 전체 지점을 지정한 일수로 자동 배분·최적화

   다. 결과 확인 및 활용

      (1) 지도 위에 번호 마커 및 실제 도로 경로선 표시

      (2) 구간별 이동시간·거리, 예상 도착·출발 시각 타임라인 제공

      (3) 관리 페이지에서 엑셀 파일 또는 구글시트로 측정 지점 데이터 갱신 가능


4. 기대 효과

   가. 경로 최적화를 통한 불필요한 이동 시간 단축 및 측정 업무 효율 향상

   나. 담당자 수작업 경로 계획 부담 해소 및 측정 결과의 일관성 확보

   다. 지점 파일만 교체하면 타 지역 전파측정팀도 동일 시스템 활용 가능

        2. 화면 캡처 1부.  끝.
